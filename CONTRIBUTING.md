# Contributing to openSIS College Edition

Thank you for your interest in contributing.

We welcome developers interested in improving
Student Information Systems for higher education.

## How to Contribute

1. Fork this repository.
2. Create a feature branch.
3. Make your changes.
4. Test your changes.
5. Commit your changes.
6. Submit a pull request.

## Contribution Areas

- Academic management
- Course registration
- Student information management
- GPA and CGPA calculations
- Examination and grading
- Transcript management
- Reporting
- User interface improvements
- Bug fixes and documentation

## Development Guidelines

- Follow existing coding conventions.
- Keep changes focused and documented.
- Test changes before submitting.
- Do not include real student information.
- Never commit passwords or API credentials.
- Preserve original openSIS copyright notices.

## Reporting Issues

Use GitHub Issues to report bugs and suggest
new features.
