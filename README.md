## Overview

**openSIS College Edition** is a customized version of openSIS Classic 9.x, developed to support the academic and administrative requirements of colleges and higher education institutions.

The project extends the original Student Information System with college-oriented academic structures and workflows, including college, faculty and department management, semester-based academic administration, course registration, credit hour management, GPA and CGPA calculations, examinations, grading and transcript management.

The goal is to provide a centralized platform for managing college academic operations, student records and institutional activities.

## Project Objectives

- Adapt openSIS Classic for higher education environments.
- Support college, faculty and department organizational structures.
- Simplify semester-based academic administration.
- Improve student registration and course management.
- Support credit-hour-based academic progression.
- Facilitate examination, grading and academic evaluation.
- Improve academic record and transcript management.

## Technology Stack

The project is based on the openSIS Classic web application architecture.

- **Backend:** PHP
- **Database:** MySQL / MariaDB
- **Web Server:** Apache
- **Frontend:** HTML, CSS and JavaScript
- **Local Development Environment:** XAMPP

Refer to the upstream openSIS documentation and the installation guide for version-specific requirements.

## Installation

This project is intended to run in a compatible PHP, Apache and MySQL/MariaDB environment.

For local development using XAMPP:

1. Install a compatible XAMPP environment.
2. Clone or download this repository.
3. Place the application directory inside `htdocs`.
4. Configure the required database.
5. Review the application's database configuration.
6. Follow the applicable openSIS installation and setup procedure.
7. Test the college-specific academic workflows.

**Important:** Do not use production student records for testing. Use a separate development database with sample data.

See [INSTALLATION.md](docs/INSTALLATION.md) for further guidance.
